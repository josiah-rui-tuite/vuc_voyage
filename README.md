# Waypoint ― Value Use Case Ledger

**VUC台帳エディタ**：価値ユースケース（VUC）を1本ずつつくり、測り、次に何を確かめるかをサポートするツールである。

HTMLファイルをダウンロードし、ダブルクリックすれば使える。インストールもアカウントもいらない。外部への通信を一切しない（CDN・フォント・画像・解析のどれも読み込まない）ので、書いた内容が手元のPCから出ることはない。

- ファイル: `vuc_ledger.html`（単一HTML・UTF-8・約492KB）
- スキーマ: `vuc-ledger/4`
- ライセンス: MIT

---

## これは何か

書籍「AI時代にスタートアップがしっかり利益を出すためのソフトウェア開発航海図」に記載された内容を実現するための一例である。
新規事業やプロダクトの検討で陥りがちな問題に対応する。

- 「この機能に価値がある」と言えるが、何をもってそう言えるのかが人によって違う
- 数字は集めたが、それが意思決定にどう効果を発揮するのか分からない
- 進めるか、方向を変えるか、やめるかを決める場面で、判断の材料が揃っていない

Waypoint は、1本の価値ユースケースについてどこまで検証が進み、次に何をしたらいいのかを指し示す。
成熟の段は L0 から L5 までの6段で、**段を上げるのは人が宣言する操作**であり、ツールは宣言できる条件が揃っているかを検査する。

## 何ができるか

画面は6つある。

| 画面 | 役割 |
|---|---|
| 今日の一手 | 全体を見渡さずに済むよう、いま効く1件だけを受け取って、その欄だけ書く |
| VUCを作る | 案を1本立てる（ウィザード） |
| 測る・判定する | 1本を丸ごと見て決める。段の宣言、ゲート4条件の判定、Continue / Pivot / Kill |
| 航海日誌 | 段ごとに「要る欄／書いた内容／根拠」を並べる。一覧と書き出しもここ |
| 設定 | しきい値・目標値・保存先。不変条件テスト（30件）もここから走らせられる |
| 使い方 | 読むだけの画面。最初の1周を手順1〜12で追える。図が8枚（すべてインラインSVG） |

書き出しは3種類。**意思決定カード**（Markdown・印刷）、**一覧CSV**、**JSON全量**（読み戻せる正本）。

すべての入力欄とボタンの横に `?` があり、「何のためか／何をするか／例」の3つが出る。

## 使い始める

### 1. ダウンロードする

このページの `vuc_ledger.html` を開き、右上の **Download raw file**（下向き矢印のボタン）を押す。GitHub 上でファイルを直接開いてもソースが表示されるだけで、ツールとしては動かない。

まとめて取得する場合は、緑の **Code** ボタンから **Download ZIP**、または

```
git clone https://github.com/<ユーザー名>/<リポジトリ名>.git
```

### 2. 開く

保存した `vuc_ledger.html` を**ダブルクリック**する。ブラウザが開いて、そのまま使える。

### 3. ［使い方］タブを読む

初回はここから始める。本書とツールの関係、最初の1周、ふだんの3つの場面（週1回30分・思いつき2分・会議前10分）が1枚ずつ図で出る。VUCが0本のときは最初の画面にも入口が出る。

## データはどこにあるか

**書いた内容はブラウザの中（localStorage）と、自分で書き出した JSON ファイルにしかない。** サーバへ送られることはない。

保存の考え方は1つだけ覚えればよい。

- **自動保存＝下書き**：入力するたびブラウザ内に残る。閉じて開き直せば戻る
- **JSON＝正式**：残したい状態は［航海日誌］から JSON を書き出す。これが正本になる

上書き保存（`Ctrl+S` で選んだファイルへ直接書く）に対応した環境では、起動時にそちらのモードを選ぶ。保存できない場合は、その場でダウンロード方式へ切り替わる。

ブラウザのデータを消す操作（履歴の削除、シークレットウィンドウを閉じる等）をすると下書きは消える。**消えて困るものは JSON にしておく。**

注意が2つある。

- `file://` で開いた場合、**同じツールを別のフォルダに置くと下書きを共有する**（ブラウザがフォルダを区別しないため）。JSON は別々なので正本は分かれる
- 同じファイルでも、ダブルクリック（`file://`）で開いたときとローカルサーバ（`http://localhost`）で開いたときでは、**保存領域が分かれる**。片方で書いた下書きはもう片方からは見えない

## 動作環境

モダンなブラウザ。JavaScript が有効であること。ネットワークは不要（オフラインで動く）。

**実機で確認したのは Chromium 149（Windows）だけである。** Chrome・Edge・Firefox・Safari の各版での確認は済んでいない（下の「未確認の事項」を参照）。表示はライトとダークの両方に対応し、OSの設定に従う（画面右上の ◐ で切り替えられる）。

本書を読んでいなくても操作はできる。ただし各欄の `?` は「この欄に何を書くかを学べる節」として本書の章・節を指すので、書く内容に迷ったときの行き先は本書になる。［使い方］タブに、本書の部（第I部〜第VI部）と段（L0〜L5）の対応表、章 → ツールのどこ の対応表が入っている。
